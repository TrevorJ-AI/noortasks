# NoorTasks desktop hub

## Register

Product UI. A companion to the existing NoorTasks web app.

## Platform

Web UI inside Electron on Windows and Linux.

## Users and purpose

People who want to keep their task server and data on their own computer and sync
with a phone. Success means opening NoorTasks, creating an account, and pairing
the phone with a single-use QR code.

## Design principles

Reuse the web app's green accent, system sans typography, spacing and controls.
Keep instructions readable in a small desktop window in an ordinary lit room.
Use native menus and tray controls. Make local network exposure an explicit
choice. Show actionable errors and loading states, label every input, preserve
keyboard focus, and keep technical details to those needed to connect a phone.

## Boundaries

No marketing treatment, decorative motion, custom account system or automatic
updates. The existing server owns setup, sign-in, pairing and data.
